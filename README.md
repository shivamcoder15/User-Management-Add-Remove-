# 👤 User Management – Add & Remove

A responsive **User Management Web App** built as a JavaScript practice project. This project allows users to add and remove user profiles dynamically while storing data in the browser using Local Storage.

## 🚀 Live Demo

https://shivamcoder15.github.io/User-Management-Add-Remove-/

## ✨ Features

* ➕ Add new users
* 🗑️ Remove users
* 💾 Local Storage data persistence
* ✅ Form validation
* 🔔 Toast notifications
* 🖼️ Profile image support with fallback
* 👤 Dynamic user cards
* 🔢 User count display
* 📱 Responsive design
* 🎨 Modern UI
* ⚡ Dynamic DOM updates

## 🛠️ Tech Stack

* HTML5
* JavaScript
* Tailwind CSS
* Local Storage
* DOM Manipulation
